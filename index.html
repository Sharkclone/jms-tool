🔐 Phiên đăng nhập JMS (token)

Đang kiểm tra...

API của JMS xác thực bằng token (không phải cookie). Nếu đã cài extension đi kèm (thư mục extension/) thì chỉ cần đăng nhập JMS như bình thường — extension tự gửi token + cookie xuống tool. Cách thủ công dự phòng: mở tab JMS đã đăng nhập → F12 → thẻ Application → Local Storage → https://jms.jtexpress.vn → copy giá trị của khóa YL_TOKEN. Token chỉ lưu trên máy này (file session.json), hết hạn thì extension tự gửi bản mới.

Đăng ký chuyển hoàn theo file — đúng quy trình trang batch của JMS

Chọn file .txt hoặc .csv chứa mã vận đơn (mỗi mã một dòng, hoặc cách nhau bằng dấu phẩy/chấm phẩy). Tool đọc file → tra cứu theo lô tối đa 200 mã/lần (giới hạn của JMS, tool tự chia nhỏ) → hiện bảng cho a kiểm tra mã nào được phép → chọn loại chuyển hoàn → lưu một lần. File Excel (.xlsx) thì lưu thành CSV rồi chọn ở đây (bản sau sẽ hỗ trợ đọc thẳng .xlsx).
