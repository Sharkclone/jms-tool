🔐 Phiên đăng nhập JMS (token)

Đang kiểm tra...

API của JMS xác thực bằng token (không phải cookie). Nếu đã cài extension đi kèm (thư mục extension/) thì chỉ cần đăng nhập JMS như bình thường — extension tự gửi token + cookie xuống tool. Cách thủ công dự phòng: mở tab JMS đã đăng nhập → F12 → thẻ Application → Local Storage → https://jms.jtexpress.vn → copy giá trị của khóa YL_TOKEN. Token chỉ lưu trên máy này (file session.json), hết hạn thì extension tự gửi bản mới.

🔄 Cập nhật tool

Phiên bản hiện tại: ?. Tool tự động cập nhật khi có bản mới — lúc khởi động bridge và lúc mở trang — không cần bấm gì. Bản cũ được sao lưu vào thư mục backups/ trước khi ghi đè, không đụng tới session.json. Nếu server.py thay đổi thì khởi động lại bridge (chạy lại py server.py) để nhận bản mới; nếu extension thay đổi thì tải lại extension trong Chrome. Hai nút trên chỉ để kiểm tra/cập nhật thủ công khi cần.

Tool chạy hoàn toàn trên máy này qua cầu nối Python (server.py). Dữ liệu gửi thẳng tới JMS bằng phiên đăng nhập của bạn.
